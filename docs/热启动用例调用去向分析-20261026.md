# 热启动44项用例：本地与远端调用分析

分析日期：2026-10-26（北京时间）。范围：`data/cases.json` 的 MW-UI-004～047，共44项、8个模块。

本轮完成44个入口及共用操作实现的静态遍历，并读取当前安装的客户端前端包、Electron主进程实现、脱敏监控记录和CDP目标。**不是44项重新执行的实测报告**，没有发送任务、安装技能、创建空间或修改客户端配置。没有给任何用例补造PASS或接口耗时。

## 1. 结论

1. 必须区分“功能的数据来源”和“当前点击是否出网”。市场数据来自远端，但分类和搜索多数对已加载列表进行本地过滤；热缓存中的案例包也可以本地打开。
2. 有两条不同通道：页面HTTP到本地工作区服务；页面IPC到Electron主进程，由主进程访问远端资产网关。仅订阅页面CDP Network会漏掉第二条通道。
3. 这44项以界面响应为主，不发送模型任务。模型切换不等于模型推理；选择工具不等于调用工具；案例回放不等于重新执行案例。
4. 44项不覆盖产品全量功能或全量API。模型推理、工具实际业务执行、登录、更新、云同步、知识库完整操作等需要另列场景。
5. 下表分类是目标操作的主要依赖；准备导航、后台轮询、预取、清理、身份校验可以产生额外调用。不能据“本地交互”断言该用例全过程零远端流量。

## 4. 现有热测框架会误导调用归因的地方

- `lib/response-observer.mjs`只捕获页面Network与`[model-proxy]`事件，未采集`assets:fetch`、`assets:fetchCasePackage`及本地IPC。此前“页面没有远端HTTP样本”不能推广为“整个MobileWork没有访问远端”。
- 页面当前地址为`mobilework-shell://app/index.html`，`lib/runtime.mjs:attach()`仍只匹配旧的`MobileWork/resources/app-dist/index.html`，本轮只读CDP确认该兼容缺口。直接批跑会在找到主窗口前阻塞；本轮不修改执行框架。
- `run-case.mjs`在准备动作之前已设置`execution`阶段；因此进入案例库、准备市场、创建空间等流量会混入execution。仅按caseId或整个execution时间窗归因不够。
- 006/012为了测返回首页会先打开案例库；027/038准备时先进入技能市场。不能把这些准备阶段资产请求当作目标功能本身的接口。
- 工具弹层的connector目录查询、首页/历史页挂载、配置应用后的版本检查可能伴随后台请求。应单独列background，而不是因时间相近自动关联。
- `safeEndpoint()`把所有非回环主机记作`local:false`，包括非HTTP的app资源；旧被动汇总因此把12条非HTTP资源计为remote。统计要先按transport过滤，再判断主机位置。
- 原被动汇总的`upstreamErrors`只计`upstream_response`的HTTP错误，漏计`request_failed`连接错误。前次6个ETIMEDOUT已人工识别，不能用upstreamErrors=0宣称模型无异常。
- 主进程`[assets-perf] ... (cache)`表示经过缓存分支，缓存分支内部也可能回源；不能仅凭该标记判定cache hit。案例包命中缓存还可能直接返回而没有HTTP样本。

## 5. 后续实测应采用的记录方式

每个目标操作保留独立actionId，与caseId、冷热轮次和操作起止关联；准备、目标交互、后台、清理分开。按以下四栏展示，而不是“本地/远端”二选一：

| 栏目 | 所需证据 |
| --- | --- |
| 页面响应 | 原有渲染时钟，明确起止终态和成功/失败 |
| 本地HTTP/IPC | 方法、路由模板或IPC动作、完成/失败、耗时；本地IPC耗时不能冒充HTTP耗时 |
| 远端HTTP | 主进程资产/模型/MCP出站，保留目标origin、脱敏路由、网络等待和失败；需要可靠关联，不采集认证信息及正文 |
| 缓存 | memory/disk/network/unknown；观测不到来源时写unknown，不能因为没有页面请求就填local-cache |

市场首屏、安装、案例预览要区分“当前热缓存路径”和“真实回源路径”。首次预热后第二轮很快可能只是读缓存，不能据此宣称远端服务很快。保留用户缓存，不为分析擅自清空。

先修复新协议主窗口识别，再补充资产主进程观测与action级边界；之后按现有串行调度实跑。安装/召唤仍用独立测试资产并正常收尾；模型实际推理和工具实际业务调用作为独立场景，不能混入44项UI热测。此次没有开发产品代码、没有新增或运行用例测试。
