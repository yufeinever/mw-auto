# 接口探测协议覆盖梳理

日期：2026-10-27。v0.0.22只能证明已观察到的流量，不能作为全客户端接口总表。v0.0.23补齐无侵入可采元数据，仍明确保留覆盖缺口。

| 类型 | v0.0.22 | v0.0.23 | 仍有的边界 |
| --- | --- | --- | --- |
| 页面HTTP/HTTPS | 请求、状态及耗时 | 增加实际HTTP响应协议、连接对端IP/端口 | 本地网关请求不能证明已转发至后端；代理对端不一定是最终服务 |
| WebSocket | 未专门采集帧 | 握手、收发帧、字节、帧频率、关闭/错误 | 不解析正文，不把帧数当业务消息数；采集前已建立连接可能缺URL |
| SSE | 识别Content-Type，排除完整流时长 | EventSource事件、数据块、字节独立统计 | fetch流无可靠业务消息计数；数据块不能当消息数或模型token |
| TCP | 进程树远端连接采样 | 明确协议、保留状态样本与记录峰值 | 短连接可漏采，采样不是建连次数或HTTP请求数 |
| UDP本地端点 | 未采集 | Get-NetUDPEndpoint + PID采样 | 只有本地绑定，不能得出远端、数据报数或流量存在 |
| Chromium UDP | 原事件可能存在但未分类 | NetLog UDP事件、可见远端数字IP、已知字节 | 仅Chromium，不是全系统UDP；字段缺失不补造 |
| QUIC / HTTP3 | 未专门分类 | QUIC事件分类；HTTP3由HTTP响应协议确认 | QUIC事件不等于HTTP3请求，更不能用UDP端口443推断HTTP3 |
| 独立worker | 未独立附加 | 启动时记录target类型数量，明确未订阅 | 页面订阅不覆盖全部worker；NetLog仍仅覆盖Chromium路径 |
| Node.js主进程/子进程HTTP | 未覆盖路径 | 保留显式缺口 | 需要在实际请求库（http/https/fetch/Undici等）及子进程增加埋点 |
| Electron session.webRequest | 未接入 | 仍未接入 | 不是Node.js原生HTTP的全覆盖工具；每事件只保留最后listener，直接注入可能替换产品钩子 |
| IPC / 命名管道 | 未统计消息 | 标记未覆盖 | 属于本地通信，不能直接算成后端HTTP负载 |

## 计数与隐私

- HTTP请求、WebSocket帧、SSE事件、网络数据块、TCP连接状态样本、UDP绑定样本分别统计。
- NetLog的TCP/UDP/QUIC可能对应同一流量的不同协议层，不跨行累加事件或字节；source数不是连接数。
- 采集前已有请求、短连接、独立worker、Node.js原生HTTP及未执行功能均可能形成盲区。不能声称接口已采集全。
- 只保存允许字段：归一化路径、协议、IP/端口、计数、字节、状态和时间。WebSocket内容、SSE正文/事件ID、认证头、查询、Cookie及原始动态ID不落盘。
- 旧批次不重写，新字段不存在时显示“旧批次未采集”。“本批未观察到”只表示该窗口内未见样本，不表示产品没有使用。
- 现场15分钟旧批次出现NetLog缓冲100%、数据丢失、65,923条允许事件被丢弃及采样提前到期。新采集器每60秒回收一段，过滤无关事件；实际分段间隔计入缺口并标记不完整。不能把分段后的记录称为连续无丢失，也不能用旧批次做完整请求量估计。

## 对用户目标的下一步

先记录静置基线，再记录功能遍历，比较远端接口频率、峰值与P95。要形成完整远端HTTP清单，最重要的剩余工作是客户端主进程和子进程请求埋点；无需生产访问日志，但需要研发提供只读诊断事件或开发版支持。系统TCP/UDP观测可补充进程和地址归属，无法恢复加密HTTP路径。后端CPU、整体容量和多用户压力仍需相应服务端或负载测试证据。

## 本版现场验证

静置批次 `probe-1793073566061-794c310e-c2fc-4a27-8df4-0b3b36b714fd` 记录68.80秒：206次页面HTTP请求、4685条允许的NetLog事件、TCP与UDP各36轮进程采样。页面取得HTTP/1.1和本地网关对端。网络成功回收2段，切段累计间隔919ms，0事件丢弃、未报告缓冲满或追踪数据丢失；存在切段缺口，所以保留部分采集状态。

观察到Chromium UDP事件，但没有观察到页面WebSocket/SSE、QUIC或进程UDP本地绑定。短时UDP事件与端点采样可以出现不同结果，不能把无绑定样本解释为没有UDP通信。本批网络层远端HTTP为0，进程层仍看到远端连接，不据此推断没有后端调用。WS/SSE计数和隐私边界通过模拟事件测试，尚无本轮真实流样本验证。13项定向测试通过；真实浏览器确认记录中刷新、停止保存和新覆盖表展示。
